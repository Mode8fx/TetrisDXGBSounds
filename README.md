# Tetris DX: GB Sounds

_Tetris DX: GB Sounds_ is a ROM hack of Tetris DX that adds six additional music tracks to the main gameplay, bringing the total to nine songs across three pages. The new music comes from the original Game Boy _Tetris_ as well as _Super Bombliss DX_ (the Japan-only enhanced release of _Tetris Blast_).

- MUSIC-1: _Tetris DX_ [A-TYPE / B-TYPE / C-TYPE]
- MUSIC-2: _Tetris_ [A-TYPE / B-TYPE / C-TYPE]
- MUSIC-3: _Super Bombliss DX_ [CONTEST / PUZZLE / TRAINING]

It also adds the ability to toggle the pinch (speed-up) music on/off by pressing Select while selecting music.

The download can be found [here](https://github.com/Mode8fx/TetrisDXGBSounds/tree/main/patches).

## Notes
